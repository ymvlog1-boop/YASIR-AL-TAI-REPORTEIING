# YASIR-AL-TAI-REPORTING — Production package

ارفع الملفات الأربعة التالية إلى جذر مستودع GitHub:
- index.html
- about.html
- privacy.html
- terms.html

## قبل طلب Google OAuth Verification
1. افتح about.html وprivacy.html وterms.html واستبدل نص "ضع هنا بريد التواصل..." ببريد دعم علني ومراقَب.
2. في Google Auth Platform > Branding:
   - Home page: رابط موقع GitHub Pages الرئيسي.
   - Privacy policy: رابط privacy.html.
   - Terms of service: رابط terms.html.
3. في Data Access أبقِ فقط الصلاحيات التي تحتاجها فعلاً، وخصوصاً gmail.send.
4. في Audience انقل التطبيق إلى In production عندما تكون جاهزاً.
5. أكمل Verification Center إذا طلب Google التحقق من الصلاحية الحساسة.

ملاحظة: هذه النسخة لا تستخدم خادماً خاصاً أو قاعدة بيانات خاصة بالموقع.
